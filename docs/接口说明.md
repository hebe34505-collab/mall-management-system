# 接口说明

在线文档：后端启动后打开 http://localhost:8080/swagger-ui.html 。

统一响应：

```json
{ "code": 0, "message": "ok", "data": {} }
```

`code` 为 0 表示成功。失败时 HTTP 状态码与 `code` 同时返回，例如 401/40100、403/40300、422/42200。

分页数据放在 `data` 中：`records`、`total`、`page`、`size`。

## 认证

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| POST | /api/auth/register | 公开 | 注册普通用户 |
| POST | /api/auth/login | 公开 | 用户名或邮箱登录 |
| POST | /api/auth/logout | 登录 | 令牌版本加 1 |
| GET | /api/auth/me | 登录 | 当前用户 |

## 商品与分类

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| GET | /api/products | 公开 | 只返回上架商品，支持 keyword、categoryId、sort、recommend、page、size |
| GET | /api/products/{id} | 公开 | 下架商品返回 404 |
| POST | /api/products | 管理员 | 新增 |
| PUT | /api/products/{id} | 管理员 | 编辑 |
| DELETE | /api/products/{id} | 管理员 | 删除，并清理购物车引用 |
| PATCH | /api/products/{id}/status | 管理员 | body: `{ "status": "ON_SHELF" }` |
| GET | /api/admin/products | 管理员 | 可按上下架筛选 |
| PATCH | /api/admin/products/{id}/stock | 管理员 | 调整库存并写流水 |
| GET | /api/categories | 公开 | 启用中的分类 |
| POST/PUT/DELETE | /api/categories | 管理员 | 新增、编辑、删除 |

删除仍被商品使用的分类会返回业务错误。

排序只允许 `newest`、`price_asc`、`price_desc`、`sales_desc`。

## 购物车、地址、订单

购物车和地址都只操作当前登录用户的数据。

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET/POST | /api/cart | 查询、加入 |
| PUT/DELETE | /api/cart/{id} | 改数量、删除 |
| DELETE | /api/cart | 清空 |
| GET/POST | /api/addresses | 地址列表、新增 |
| PUT/DELETE | /api/addresses/{id} | 编辑、删除 |
| POST | /api/orders | 创建订单，可用请求头 `Idempotency-Key` |
| GET | /api/orders | 我的订单 |
| GET | /api/orders/{id} | 我的订单详情 |
| POST | /api/orders/{id}/cancel | 取消待发货订单 |
| GET | /api/users/me/summary | 个人订单统计 |
| PUT | /api/users/me | 修改资料，不能修改角色 |
| PUT | /api/users/me/password | 修改密码 |

创建订单的金额由数据库单价乘以数量得到。请求体使用 `cartItemIds` 或 `items` 其中一种，并必须提供 `addressId`。

## 管理后台

全部要求管理员角色。

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | /api/admin/orders | 订单列表 |
| GET | /api/admin/orders/{id} | 订单详情 |
| PATCH | /api/admin/orders/{id}/status | 合法状态变更 |
| GET | /api/admin/users | 用户列表 |
| PATCH | /api/admin/users/{id}/status | 启用或禁用，不能禁用自己，不能改角色 |
| GET | /api/admin/stats/overview | 用户数、商品数、有效订单、销售额、近期订单、热销商品 |
| GET | /api/admin/stats/trend?days=7 | 按日订单数和销售额 |
| GET | /api/admin/logs | 操作日志 |
| GET | /api/admin/categories | 全部分类，含停用 |
